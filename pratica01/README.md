# Laboratório de Programação Modular - Prática 1

Repositório contendo as soluções da **Prática 1 (Partes 1 e 2)** da disciplina de Laboratório de Programação Modular da PUC Minas.

## 📚 Sobre os Exercícios

O projeto consolida os conceitos iniciais de **Orientação a Objetos (OO)**, encapsulamento, manipulação de vetores, além do tratamento de Strings e Datas, divididos nos seguintes cenários:

### 1. Sistema de Cálculo de IMC
Implementação da classe `Pessoa` responsável por receber os dados físicos do usuário para calcular e retornar o Índice de Massa Corporal (IMC), classificando a faixa de obesidade.

### 2. Chapéu Seletor e Cadastro de Hogwarts
Sistema interativo utilizando a classe `Aluno` para gerenciar a matrícula de bruxos, incluindo:
- **Chapéu Seletor:** Classificação automática nas casas (Grifinória, Sonserina, Corvinal, Lufa-Lufa) com base em pontuações de atributos (coragem, inteligência, ambição e lealdade).
- **Tratamento de Datas e Strings:** Validação de datas de nascimento utilizando `LocalDate`, cálculo de maioridade mágica (17 anos) e formatação/padronização de nomes de casas.
- **Geração Automática:** Criação de login de usuário (primeira letra do nome + sobrenome) e código de matrícula padronizado (ex: `HP-2026-01`).
- **Menu Interativo:** Sistema com limite de 10 cadastros que permite buscar alunos por sobrenome, filtrar por casa, listar maiores/menores de idade e exibir relatórios completos.
